# Package index

## All functions

- [`cbb_build_prompt()`](https://vjcitn.github.io/CBBBioc/reference/cbb_build_prompt.md)
  : build the agent-facing prompt text for a question
- [`cbb_fetch_files()`](https://vjcitn.github.io/CBBBioc/reference/cbb_fetch_files.md)
  : fetch the files associated with a question into a destination
  directory
- [`cbb_filecache()`](https://vjcitn.github.io/CBBBioc/reference/cbb_filecache.md)
  : get (creating if needed) the BiocFileCache used for CompBioBench
  downloads
- [`cbb_question()`](https://vjcitn.github.io/CBBBioc/reference/cbb_question.md)
  : look up a single question record in v1qs
- [`cbb_setup_workspace()`](https://vjcitn.github.io/CBBBioc/reference/cbb_setup_workspace.md)
  : set up a self-contained folder for an agent to answer a v1qs
  question
- [`cbb_url()`](https://vjcitn.github.io/CBBBioc/reference/cbb_url.md) :
  form the url for retrieva of a CompBioBench datasets
- [`fixup_files()`](https://vjcitn.github.io/CBBBioc/reference/fixup_files.md)
  : get list of vectors of filenames when appropriate
